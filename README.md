# LayerPaint · 图层图片编辑器

一个**纯前端、零依赖**的图层式图片处理项目（原生 HTML + CSS + JavaScript，无需构建、无需安装任何包）。类似迷你版 Photoshop 的图层工作流：多图层叠加、混合模式、绘图工具、滤镜调整、撤销重做、导出成品。

## 运行

方式一（最简单）：直接**双击 `index.html`** 用浏览器打开。

方式二（本地服务器）：

```bash
cd layer-image-editor
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 建议 Chrome / Edge / Firefox / Safari 16+（滤镜用到 Canvas 2D 的 `ctx.filter`）。

## 功能一览

### 图层系统（核心）
- **新建图层**：空白图层，随时叠加
- **导入图片为图层**：文件多选、拖拽文件到画布；文档未被编辑时，首张图片自动决定画布尺寸（上限 1800px），之后导入的图片等比缩放居中放入；导入后可用「缩放/变换」工具任意调整图片大小
- 图层**显隐**（👁 / 🙈）、**双击重命名**
- **排序**：按钮上移/下移 + 列表内**拖拽排序**
- **复制图层**、**删除图层**、**向下合并**
- 图层**不透明度**（0–100%）
- **16 种混合模式**：正常 / 正片叠底 / 滤色 / 叠加 / 变暗 / 变亮 / 颜色减淡 / 颜色加深 / 强光 / 柔光 / 差值 / 排除 / 色相 / 饱和度 / 颜色 / 明度
- 图层缩略图实时刷新

### 绘图工具
| 工具 | 说明 |
|---|---|
| 🖌 画笔 | 大小 1–300、硬度（软边）、不透明度 |
| 🧽 橡皮擦 | 同画笔参数，按不透明度擦除 |
| 🪣 油漆桶 | 泛洪填充，可调容差 0–255 |
| ▭ 矩形 / ◯ 椭圆 | 填充或描边，Shift 拖拽为正方形/正圆；拖拽过程实时预览实际填充/描边效果并显示尺寸 |
| T 文字 | 选项栏输入内容与字号，点击画布放置 |
| ✥ 移动图层 | 拖拽搬移当前图层像素 |
| ⤢ 缩放/变换 | 拖四角等比缩放（对角为锚点），Shift 自由拉伸，拖内容中间移动；带变换框与尺寸提示，另支持 50%–200% 数值缩放与「适应画布」一键铺满 |
| 💧 吸管 | 从合成结果取色 |

### 调整与滤镜（作用于当前图层）
- 实时预览滑杆：**亮度 / 对比度 / 饱和度 / 色相 / 模糊**，点「应用」烘焙生效，「重置」取消预览
- 一键滤镜：**黑白 / 反色 / 复古 / 锐化（3×3 卷积）/ 像素化 / 模糊**

### 文档与其它
- 新建文档（尺寸 1–8000、白/黑/透明背景）
- 导出 **PNG / JPG**（拍平所有可见图层）
- **撤销 / 重做**：整档快照，上限 20 步
- 缩放：按钮、`Ctrl/⌘ + 滚轮`、适配窗口、1:1；状态栏显示尺寸/缩放/坐标
- 透明区域显示为棋盘格

## 实现要点

- **图层 = 离屏 canvas**：每个图层都是与文档等大的 `canvas`，主画布每帧按「底→顶」顺序以 `globalAlpha` + `globalCompositeOperation`（混合模式）合成，透明棋盘格是 CSS 背景。
- **笔迹缓冲**：画笔/橡皮先把印章画进离屏缓冲，再按工具不透明度一次性合成回图层，保证单笔不透明度均匀、不会越画越深。
- **撤销 = 整档快照**：每步保存全部图层的元数据 + 像素克隆，实现简单且状态绝对一致。
- **滤镜**：主要基于 `ctx.filter`（CSS filter 语法）离屏重绘烘焙；锐化为手写 3×3 卷积。

## 已知限制

- 「移动图层」是像素级搬移，移出画布的部分会被裁剪（松手即定型）
- 撤销为快照式：超大文档（多图层、接近 1800px）时内存占用较高，历史步数上限 20
- 滤镜预览依赖较新的浏览器（`ctx.filter`）
